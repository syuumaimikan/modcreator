# Mod Studio

Mod Studio は、Minecraft の Mod・プラグイン・データパック・リソースパック・統合版アドオンを、1 つのプロジェクトからまとめて作るデスクトップアプリです。Java と JavaFX で作られています。

アイテム、ブロック、Mob、ディメンション、GUI、機械などを画面上で作ると、選んだすべてのローダーと Minecraft バージョンに向けて、ソースプロジェクトとファイルを生成します。Mod とプラグインは、そのまま Gradle で jar までビルドできます。「遊んでみる」ボタンを押すと、その Mod を入れたゲームやテストサーバーが起動します。

## 主な機能

### 出力先

- 1 つのプロジェクトから、Forge、NeoForge、Fabric、Quilt、Paper / Spigot、Folia、データパック、リソースパック、統合版へ同時に出力
- 新規プロジェクトでは「Mod」「データパック」「リソースパック」「サーバープラグイン」「統合版アドオン」とスターターテンプレートから選ぶ
  - 選んだ出力先で作れない要素はサイドバーに出さず、ID の呼び方 (Mod ID / 名前空間 / プラグイン ID) やパッケージ名の有無、依存関係 (`dependencies`) も管理
- Minecraft 1.20.1 から 26.1 までの 10 バージョン（1.20.1, 1.20.4, 1.20.6, 1.21.1, 1.21.4, 1.21.8, 1.21.9, 1.21.10, 1.21.11, 26.1）に同時出力
- 1.21.9 以降の `[major, minor]` 形式 `pack.mcmeta` (`min_format` / `max_format`) や、26.1（Java 25・非難読化ビルド）に対応
- データパックとリソースパックは、選んだ全バージョンで使える 1 つの zip (バージョンごとのオーバーレイ入り) も出力
- 互換性ページで、要素ごと・出力先ごとに状態を確認
  - 状態は「対応」「代替 (シムや簡易版で動作)」「非対応 (Mod 専用等)」の種類と理由を表示

### コンテンツ

- **アイテム**
  - 食べ物、剣とツール、防具、燃料、レア度、弓・クロスボウ・盾・トライデント・投擲アイテム・エリトラ（滑空装備）を設定
  - 右クリック・エンティティ攻撃・手持ちティック時プロシージャ
  - 曲を割り当てたレコード (1.21 以降はジュークボックスで再生)
  - Shift キーで出る詳しいツールチップと Minecraft 風プレビュー
- **ブロック**
  - 立方体、柱、作物、ハーフブロック、階段、フェンス、塀、ドア、トラップドア、ボタン、感圧板、カーペットなどの形状
  - レッドストーン出力・接続、水没対応 (`waterloggable`)、右クリック・踏みつけ・ランダムティック・隣接更新プロシージャ
  - 立体プレビュー
- **液体 (Fluid)** (Mod ローダー)
  - 静止・流動液体、液体ブロック、自動生成バケツ、発光、粘度・密度・溶岩挙動・接触時プロシージャ
- **防具・防具装飾・旗の模様**
  - 防具素材（部位防御、強度、ノックバック耐性、装着音、修理素材）と着用テクスチャ自動生成
  - 防具装飾 (`armor_trim`) と鍛冶型テンプレート生成、カスタムの旗・盾の模様 (`banner_pattern`)
- **3D モデル**
  - キューブとボクセルの 3D エディタ（3D ビュー上での `Alt+ドラッグ` 移動 / `Shift+ドラッグ` リサイズ対応）
  - Java モデル / Blockbench `.bbmodel` / 統合版 `.geo.json` のインポートに対応
  - ボーンとキーフレームのアニメーション (位置、回転、拡大、補間、ループ)
- **シェーダー**
  - GLSL コアシェーダー (`core`)・ポストプロセスシェーダー (`post`)・インクルード (`include`) を編集
  - 52 種類のノードグラフから GLSL を自動生成
  - **CPU プレビュー**: `@block`, `@gem`, `@gradient`, `@scene` サンプルに対し、光の明るさ調整と距離フォグを含めてリアルタイム比較
- **テクスチャ**
  - レイヤー（追加・削除・表示切替・下へ結合）、矩形範囲選択・切り取り・コピー・貼り付け対応ピクセルエディタ
  - フレームアニメーション: オニオンスキン、再生プレビュー、`.mcmeta` と統合版 flipbook の出力
- **その他**: クリエイティブタブ、サウンド (ogg の取り込みと試聴)

### データ

- レシピ: 作業台（残余アイテム維持対応）、かまど系、石切台、鍛冶台、1.20.5+ Data Component 付与
- ルートテーブル: 既存テーブルへの注入 (`inject`)、ドロップ増加・爆発減衰・レベル付きエンチャント・カスタム名/説明文・ブロック状態条件
- 進捗（`slept_in_bed` 等含む全トリガー）、タグ（`fluid` 含む）、`mcfunction`、プレディケート、アイテム修飾子

### ゲームプレイ

- **ステータス効果・ポーション・エンチャント・ダメージタイプ・絵画・レコード曲**
- **カスタムコンテナ・車両/エンティティ・村人の職業・カスタムレシピ種別** (Mod ローダー)
  - `Container` (`BlockEntity` + `AbstractContainerMenu` + `Screen` + ホッパー/時間経過加工レシピ)
  - `CustomEntity` (中立/友好/敵対/投射物/騎乗可能、AIゴール、自然スポーン、スポーンエッグ、`EntityRenderState` 対応)
  - `Profession` (POIワークステーションとレベル別取引)、`CustomRecipeType`
- **ポータル・ワールド生成** (`Portal`, `WorldFeature`: 鉱脈・パッチ・ツリー・スパイクとバイオーム修飾子)
- **MOD設定とMixin** (`ModConfig`: TOML/JSON 設定、`Mixin`: `mixins.json` と `@Mixin` Java スタブ)

### ロジック

- **プロシージャ**
  - 33 種類のきっかけ (cron とインターバルを含む)、216 種類の手順 (飛び道具の発射、アイテムの修飾、ルートを渡す、ダイアログ、取引商人、カスタム画面、現実の時刻を含む)、52 種類の条件を組み合わせる
  - 同じロジックを 3 つの書き方で編集でき、どれで書いても互いに変換される
    - ブロック (ビジュアルスクリプト)
    - ノードグラフ
    - テキストのスクリプト
- **コマンド**
  - 引数とサブコマンドの木構造
  - タブ補完
  - 権限
- **コードファイル**: Java などを直接書いて、生成プロジェクトに追加
- **出力先ごとの分岐**: 「プラットフォーム」条件と「バージョン」条件は生成時に判定され、出力先ごとに一致する側だけが出力される

### ワールド

- **Mob とボス**
  - ステータス、装備、見た目 (3D モデル)
  - アニメーション付きのモデル: 待機、歩き、被ダメージ、攻撃、死亡を状態に合わせて再生
  - 行動、フェーズ、ボスバー
  - 名前の翻訳
- **取引商人**: 村人や行商人に決まった取引だけを持たせて呼び出す。プロジェクトのアイテムも値段や商品に使える
- **パーティクル演出**: 点、円、球、らせん、線、渦巻き、四角、円すい、星、波
- **構造物**: ボクセルエディタ、宝箱のルート、自然生成
- **バイオームとディメンション**

### 演出

- **カットシーン (カメラワーク)**
  - カメラのキー (位置、向き、注視点、動き方) をタイムラインで編集し、上面・側面図と **3D 一人称カメラ視点プレビュー** で確認
  - 時刻に合わせた文字、サウンド、コマンド。Java 版 / 統合版ともスニークスキップと元位置復帰に対応
- **ダイアログ**
  - お知らせ、確認、複数ボタンの 3 形式。1.21.6 以降は専用ダイアログ画面、それ以前はクリック可能なチャット、統合版では Script API `@minecraft/server-ui` フォームとして出力
- **カスタム画面とHUD** (Mod の出力先)
  - 背景画像、パネル、画像、文字、ボタン、ゲージ、アイテム、エンティティ、テキスト入力欄、スライダー、チェックボックス、スクロールリスト、アイテムスロット表示を配置
  - ドラッグで配置し、見た目をそのままプレビュー。フェードイン、スライド、ポップ、脈動、揺れ、点滅、視線追従などの動き
  - 画面として開くものと、ホットバーの上などに常に出すオーバーレイ (HUD) の 2 種類。ボタンでプロシージャの実行、別の画面、Web ページ、コマンド
  - スコア、プレイヤー名、体力、座標、ディメンション、現実の日時、FPS、再生中のメディア (Windows) などを文字やゲージに表示
- **アイコンフォント**: テクスチャを `:ruby:` のように文字として使い、チャット、タイトル、画面、ツールチップに埋め込む
- **UI テーマ**: エンチャントの輝き、GUI テクスチャの差し替え、スプラッシュテキスト、ツールチップの枠、画面のボタン

### システム

- **インベントリ GUI**
  - スロットごとの表示とクリック動作
  - 背景 (パネルの自動描画または自作テクスチャ)、タイトルの色
  - 開くときのアニメーション (スロット順、行、列、中央から)、スロットのアイテムのフレームアニメーション
  - 開いたときとクリックしたときの音
- **HUD・タイマー**: サイドバー、ボスバー、アクションバー
- **外部 API 連携**
  - 非同期 HTTP と JSON パス抽出
  - ステータスコードで処理を分岐
  - シークレットは出力に埋め込まない
- **エネルギー・リソース**: 蓄積型 (マナ、エネルギー) と応力型 (回転数と応力)
- **機械・装置**
  - 生産、消費、蓄積
  - 隣接・範囲・ビームでの転送
  - 過負荷、汚染
  - 天体条件 (空、昼、夜、満月)
- **マルチブロック構造**
  - 回転を含めた認識と自動建築
  - 構造ごと動かすコントラプション
  - **組み立て式の機械** (Immersive Engineering 風): 形を作って工具で組み立て、投げ込んだアイテムをレシピで加工。入力口と出力口、処理時間、リソースの消費、副産物、待機中と稼働中のアニメーション、分解

### ツール

- **テストプレイ**
  - Mod を入れたクライアントやテストサーバー、Paper サーバーを起動
  - データパック、リソースパック、統合版アドオンはゲームにインストール
- **ホットリロード**
  - テスト中に編集すると、データ部分 (関数、プロシージャ、レシピ、ルートテーブル、進捗、タグ) を作り直して `/reload` で反映
  - コードやアセットの変更で再起動が必要なときは知らせる
- **Undo / Redo・クイック検索 (`Ctrl+K`)・Git 連携**: プロジェクト変更の取り消し/やり直し、要素一覧での複数選択一括複製/削除、検索ダイアログ、Git ステータス/コミットダイアログ
- **既存 Mod / パックの読み込み・編集**: `.jar` (Forge / NeoForge / Fabric / Quilt / Paper / Folia)、`.zip`/フォルダ（データパック・リソースパック）、統合版 `.mcaddon`/`.mcpack` をドラッグ＆ドロップや「既存MOD / パックを読込」・CLI (`--import`) から読み込んで編集・再出力可能
- **コードエディタ強化**: 検索と置換 (`Ctrl+F` / `Ctrl+H`)、対応括弧のハイライト、自動インデント、構文補完 (`Ctrl+Space`)
- **ボクセルエディタ強化**: 操作履歴 (Undo/Redo)、X/Z 軸反転、Y 軸 90° 回転
- **翻訳表**: 全言語の翻訳を 1 か所で編集
- **問題チェック**: 入力中に自動で検証
- **生成ファイルのプレビュー**
- **Gradle ビルド**: 配布用の zip と jar を出力
- **安全な名前変更**: ID や Mod ID を変えると、参照している箇所もまとめて書き換える

### UI

- 日本語 / English / 中文 / 한국어
- ライトテーマとダークテーマ
- 絵文字は使わず、アイコンだけを使用

### プラットフォーム固有の制限事項

- クライアント/ローダー拡張機能（`Fluid`, `Container`, `CustomEntity`, `ModConfig`, `Mixin`, `Portal`, `CustomRecipeType`, `Screen`, `KeyBind`）は Mod ローダー専用のため、データパック/プラグイン/統合版には生成されません（互換性・検証ページに理由を表示）
- シェーダープレビューは Pure JavaFX による CPU 計算で動作します（実ゲーム GPU 描画前の近似確認用）

データパックとプラグインでは、独自アイテムはカスタムモデルデータ付きのバニラアイテムで再現され、見た目はリソースパックで変わります。各ローダーや API のバージョンは、プロジェクトの「概要」ページで変更できます。

1.20.1 で使えない機能には、代わりの仕組みを生成します。

- 例: マクロの代わりにスコアで引数を渡す
- 例: `random` コマンドの代わりに UUID から乱数を作る

## 必要なもの

- **JDK 21 以上** (26.1 以降の出力ビルドには **JDK 25**)
  - アプリの実行と、生成した Mod・プラグインのビルドの両方に使います
  - 1.20.1 / 1.20.4 向けの Mod は Java 17、1.20.6〜1.21.11 は Java 21、26.1 は Java 25 でビルドされます
  - JDK の場所は設定画面で指定できます
- **インターネット接続**
  - 初回ビルドのときに Gradle、Minecraft、ライブラリをダウンロードするためです
- **Minecraft の利用規約 (EULA) への同意**
  - テストサーバーを起動するときに必要です
  - 画面のチェックボックスで、利用者自身が同意します

## 起動方法

```bash
./gradlew run
```

Windows のコマンドプロンプトでは `gradlew.bat run` を使います。

起動したら「新規プロジェクト」を選ぶか、「サンプルを開く」でルビー Mod の見本を開いてください。見本には、上に挙げたほぼすべての機能の使用例が入っています。

起動オプションは `-PappArgs` で渡します。

```bash
./gradlew run -PappArgs="--lang=ja --theme=dark"
```

| オプション | 内容 |
| --- | --- |
| `<file.msproj>` | 指定したプロジェクトを開く |
| `--lang=ja\|en\|zh\|ko` | 表示言語 |
| `--theme=light\|dark` | テーマ |
| `--snapshot=<dir>` | 主な画面のスクリーンショットを書き出して終了 (確認用) |

## コマンドラインでの利用

画面を開かずに生成やビルドができます。`installDist` で作った `build/install/ModStudio/bin/ModStudio` からも同じように使えます。

```bash
./gradlew run -PappArgs="--sample sample.msproj"
```

```bash
./gradlew run -PappArgs="--validate sample.msproj"
```

```bash
./gradlew run -PappArgs="--generate out sample.msproj 1.20.1,1.21.8 fabric,paper,datapack"
```

```bash
./gradlew run -PappArgs="--build out/fabric-1.21.8"
```

| コマンド | 内容 |
| --- | --- |
| `--sample <file>` | サンプルプロジェクトを書き出す |
| `--import <artifact> <file>` | 既存の `.jar` / データパック / リソースパック / `.mcaddon` を `.msproj` として読み込む |
| `--validate [file]` | 問題チェックの結果を表示 |
| `--generate <dir> [file] [versions] [targets]` | 出力先ごとのファイルを `<dir>/<出力先>-<バージョン>` に生成。versions と targets はカンマ区切りで、省略時はプロジェクトの設定に従う。パック類は `<dir>/dist` に zip で出力し、複数バージョンのときは全バージョン共通の `-all.zip` も出力 |
| `--build <dir> [tasks...]` | 生成した Gradle プロジェクトをビルド (既定は `build`) |

## 保存場所

| 内容 | 場所 |
| --- | --- |
| プロジェクト | `<プロジェクト>/<modid>.msproj` (JSON) |
| シークレット (API キーなど) | `<プロジェクト>/secrets.local.properties` (プロジェクトファイルと出力には含まれず、.gitignore にも自動で追加) |
| 生成されたソース | `<プロジェクト>/output/<出力先>-<バージョン>` |
| テスト実行の作業フォルダ | `<プロジェクト>/output/<出力先>-<バージョン>/run` |
| 配布用ファイル | `<プロジェクト>/dist` |
| アプリ設定 | `~/.modstudio/settings.json` |
| 新規プロジェクトの既定の保存先 | `~/ModStudio` |

## ソースの構成

| パッケージ | 役割 |
| --- | --- |
| `modstudio.core` | プロジェクトのデータ構造、ロジック定義、検証、互換性の判定、名前変更、バニラの ID 一覧 |
| `modstudio.gen` | 各プラットフォーム向けのコード、JSON、mcfunction、アセットの生成 |
| `modstudio.build` | Gradle Tooling API によるビルドとテスト実行 |
| `modstudio.ui` | JavaFX の画面、エディタ、3D ビュー、ノードグラフ |
| `modstudio.i18n` | UI の翻訳 (`src/main/resources/modstudio/i18n`) |

設計の詳細は [docs/design](docs/design) にあります。
