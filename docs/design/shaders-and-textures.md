# シェーダーとテクスチャアニメーション

## シェーダー

シェーダー要素 (`Systems.Shader`) は、リソースパックに入る GLSL ファイルを 1 つか 2 つ持ちます。

| 種類 | 出力先 | 用途 |
| --- | --- | --- |
| コアシェーダー (core) | `assets/minecraft/shaders/core/<program>.vsh` と `.fsh` | バニラの描画プログラムを置き換える (エンティティ、地形、文字、空など) |
| インクルード (include) | `assets/minecraft/shaders/include/<name>.glsl` | 複数のシェーダーで使う関数をまとめる |

出力は `AssetGen.shaders()` が行います。Mod の jar とリソースパックに入ります。データパックとプラグインの出力では、リソースパックで配布する扱いです。統合版はカスタムのコアシェーダーを読み込まないので出力しません。

### バージョンの違い

シェーダーのソースは Minecraft のバージョンで大きく変わるので、シェーダーごとに出力するバージョンの範囲を指定できます。

| バージョン | 主な違い |
| --- | --- |
| 1.20.1 から 1.21.1 | プログラムごとに JSON の定義がある。`#moj_import <fog.glsl>` |
| 1.21.4 | プログラム名がまとめられた (`entity` など)。`#moj_import <minecraft:fog.glsl>` |
| 1.21.8 | JSON の定義がなくなり、uniform はブロック (`Globals`、`DynamicTransforms`) にまとめられた |

各バージョンのプログラム名とインクルード名の一覧は、`src/main/resources/modstudio/shaders/programs.properties` に名前だけを持っています。エディタは、この一覧で候補を出し、存在しない名前に警告します。

### エディタ

- **「ゲームから読み込む」**
  - この PC の Minecraft ランチャーの `versions/<v>/<v>.jar` から、選んだプログラムの元のソースを読み込みます
  - バニラのソースはアプリに同梱していません。利用者の環境にあるゲームから読み込む形です
  - 読み込むと、出力するバージョンの範囲をそのバージョンに合わせます
- **スニペット**
  - 引数だけを使う補助関数を `void main` の前に挿入します
  - 関数: グレースケール、彩度、色相、色付け、ポスタリゼーション、明滅、乱数、波、リムライト、発光
  - 名前はすべて `ms_` で始まるので、バニラの関数と衝突しません
- **チェック**
  - `#version` があるか
  - `void main()` があるか
  - かっこの数が合っているか
  - 存在しないプログラム名ではないか
  - 結果は問題ページにも出ます

## テクスチャアニメーション

テクスチャは、ゲームと同じく「正方形のフレームを上から下へ並べた縦長の画像」で持ちます。`TextureAsset.frameTime` (1 フレームの tick 数、0 は静止画) と `interpolate` (フレーム間の補間) を設定します。

- **Java 版**
  - `<texture>.png.mcmeta` に `{"animation": {"frametime": N, "interpolate": true}}` を出力します
- **統合版**
  - ブロックは `textures/flipbook_textures.json` で動かします (`ticks_per_frame`、`blend_frames`)
  - アイテムのアイコンは動かないので、最初のフレームだけを出力します
- **画面上のプレビュー**
  - サムネイル、3D ビュー、ブロックのプレビューは最初のフレームを表示します

テクスチャエディタでは、次の操作ができます。

- フレーム数の変更 (増やすと最後のフレームを複製)
- フレームの複製と削除
- カンマとピリオドでのフレーム移動
- オニオンスキン (前のフレームを薄く表示)
- ゲームと同じ速さの再生プレビュー

縦長の PNG を読み込むと、自動でアニメーションとして扱います。
