# 機械・リソース・マルチブロック

Create、Thaumcraft、Astral Sorcery、Botania のような技術系・魔術系の仕組みを、データパックの範囲で動くように設計しています。実装は `gen/MachineGen.java` です。Mod でもプラグインでも、同じ mcfunction で動きます。

## 要素

| 要素 | 内容 |
| --- | --- |
| リソース | エネルギー、マナ、アスペクトなどの量。2 つのモデルがある (後述) |
| 機械 | ブロックに結び付く装置。入出力、間隔、転送方法、条件、過負荷を設定 |
| マルチブロック | 中心ブロックの周りの立体パターン。回転を含めて認識し、自動で建てることもできる |

リソースのモデルは次の 2 つです。

- **蓄積型 (buffer)**: 量が機械の間を流れる
- **応力型 (stress)**: 容量と需要の釣り合いを取る (回転数と応力)

## 機械の実体

機械は「ブロック + マーカーエンティティ」で表します。マーカーのタグとスコアは次のとおりです。

- **タグ**
  - `<ns>.machine`: すべての機械
  - `<ns>.m.<name>`: 機械の種類
  - `<ns>.has.<res>`: リソースを持つ機械
- **スコア**
  - `<ns>.mcd`: クールダウン
  - `<ns>.mst`: 状態 (0 待機、1 稼働、2 過負荷)
  - `<ns>.rpm`: 回転数
  - `<ns>.r.<res>`: 量
  - `<ns>.c.<res>`: 容量
  - `<ns>.su.<res>`: 応力
- **汚染**: `#<res> <ns>.pollution` の 1 か所で、ワールド全体の量を数えます

## 設置

1. `placed_block` の進捗で、機械のブロックが置かれたことを検知します。
   - この形式は全バージョンで `location` の条件リストを使います。1.20 (23w18a) からこの形式です。
2. 報酬の関数が、目線から 0.1 ブロックずつ最大 70 回進む光線を飛ばし、まだマーカーのないブロックを探します。
3. 見つけたら、マーカーを置いて初期化します。

## 毎 tick の処理

```
execute as @e[type=marker,tag=<ns>.machine] at @s run function <ns>:machines/_tick
  -> 種類ごとに machines/<m>/tick
     -> ブロックが壊れていれば broken (onBreak の手順を実行し、マーカーを消す)
     -> そうでなければ live: 間隔を数え、満ちたら cycle
cycle: マルチブロックの確認、天体の条件、消費量の確認、応力網の計算 -> work
work:  消費と生産、あふれた分の汚染、パーティクル、onCycle の手順 -> push
push:  隣接・範囲・ビームで送り先へ渡す (ビームは再帰で中継)
```

天体の条件は次のように判定します。

- **空が見える**: `positioned over motion_blocking` で、ブロックが真上にないことを確かめます
- **昼、夜、満月**: `time_check` の述語で調べます

## 応力網 (Create 風)

1. 応力型のリソースを持つ機械から、つながった機械をたどって `<ns>.net` のタグを付けます。
2. 網全体の容量、需要、回転数を合計します。
3. 需要が容量を超えると、すべての機械が過負荷 (`mst=2`) になり、`on_overload` を 1 回だけ実行します。過負荷のときの動作は次の 3 つから選べます。
   - 停止
   - 破壊
   - 爆発 (TNT の導火線は 1.20.4 以降 `fuse`、1.20.1 は `Fuse`)

## マルチブロックとコントラプション

- **`multiblock/<name>/check`**
  - 4 方向の回転 r0 から r3 を順に試し、一致しないセルが 1 つでもあればその向きは不成立とします
  - 結果を `#mb`、向きを `#mbr` に入れます
- **`build`**: パターンをそのまま設置します
- **コントラプション**: 構造ごと動かします
  1. **持ち上げる (`lift`)**: ブロックを `block_display` に置き換えます
  2. **動かす (`go`)**: 補間付きの `data merge` で動かします
  3. **置く (`land`)**: 指定した位置に置き直し、ディスプレイを消します

## 確認用の関数

- `machines/<m>/info`: 一番近い機械の状態をチャットに表示します
- `machines/<m>/build`: ブロックとマーカーをまとめて置きます (テスト用)
