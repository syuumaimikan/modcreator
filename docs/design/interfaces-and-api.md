# GUI・HUD・コマンド・外部 API

サーバー向けの機能です。実装は `gen/InterfaceGen.java` と `gen/BridgeGen.java`、ランタイムのテンプレートは `src/main/resources/modstudio/runtime/` にあります。

## インベントリ GUI (メニュー)

- 行数と、スロットごとのアイテム、名前、説明、クリック時の手順を設定します。
- **Mod とプラグイン**
  - 本物のチェスト型 GUI を開きます
  - クリックすると、スロットの手順の関数を実行します
- **データパック**
  - 同じ内容をチャットのクリックできるメニューで代用します (互換性ページでは「代替」)

## HUD・タイマー

- サイドバー、ボスバー、アクションバーに、スコアやタイマーの値を差し込んで表示します。
- タイマーの開始、停止、加算は、プロシージャの手順で操作します。終了すると `onFinish` の手順を実行します。
- 1.20.1 では、サイドバーの値を動的な書式で更新できません。開いたときの値で表示します。

## コマンド

- **引数**
  - 引数の木構造 (サブコマンド、文字列、整数、プレイヤー、選択肢) で作ります
  - 選択肢からタブ補完を作ります
- **権限**: レベルで指定します
- **分岐と引数の受け渡し**
  - 分岐ごとに、引数をストレージ `<ns>:args a` にコピーします
  - 整数の引数は、スコア `$name <ns>.args` にも入れます
  - 1.20.1 ではマクロが使えないので、このスコアを使います
- **データパック**
  - 独自のコマンドは作れません
  - 代わりに `/trigger` で呼べるようにします (互換性ページでは「代替」)

## 外部 API (HTTP)

- **リクエストの設定**
  - メソッド、URL、ヘッダー、本文を設定します
  - レスポンスの JSON から、ドット区切りのパス (例 `player.stats.Bedwars.wins`) で値を取り出し、スコアやストレージに入れます
- **分岐**
  - ステータスコードで、成功 (2xx)、クライアントエラー (4xx)、サーバーエラー (5xx)、失敗 (通信できない) に分けます
- **非同期実行**
  - Mod とプラグインが非同期で実行します。ゲームの tick を止めません
  - 終わったら、メインスレッドで手順の関数を呼びます
- **データパックからの呼び出し**
  - Mod とプラグインの出力では、タグとスコアを使った橋渡し (`BridgeGen`) で Java 側に依頼します
  - データパックだけの出力では通信できないので、「失敗」の分岐を実行します
- **きっかけ**
  - interval と cron で、定期的に実行できます
  - 例: Hypixel の統計の取得、Discord の Webhook への通知

### シークレット

- **保存場所**
  - API キーや Webhook の URL は `{secret:NAME}` と書いて参照します
  - 値はプロジェクトフォルダの `secrets.local.properties` に保存し、`.gitignore` にも自動で追加します
- **生成物に含めない**
  - 生成したソース、jar、zip には、値を一切含めません
  - サーバーでは、Mod なら `config/<modid>-secrets.properties`、プラグインならプラグインフォルダの `secrets.properties` から読みます
- **テストプレイ**
  - その実行用のフォルダにだけ、値をコピーします
- **ログ**
  - 値を表示しないようにしています
